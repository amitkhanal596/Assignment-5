# Assignment 5: Shader Graphs (Lightsaber)

Unity 6000.5.9f1, URP.

## How to run
Open `Assets/Scenes/SampleScene.unity`, press Play, and click inside the Game view.

| Key | Action |
|---|---|
| Space | Turn the lightsaber on / off |
| 1 – 6 | Change the blade colour |
| K | Switch between a regular and a Kylo Ren lightsaber |

## Part 5
- Kylo Ren mode: a second shader graph (`UnstableBladeShader`) makes the blade crackle, crossguard side blades appear, and extra post-processing (film grain, chromatic aberration) turns on.
- Colour switching with the number keys.
- The blade lights up the floor with a point light.
- Power on / off sound effects.
